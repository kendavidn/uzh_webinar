# UZH webinar: Yaoundé COVID-19 serosurvey data

English-language subset of a 2020 SARS-CoV-2 serosurvey in Yaoundé, Cameroon (971 participants).

- Data: [yaounde_covid_en.zip](https://github.com/kendavidn/uzh_webinar/raw/main/yaounde_covid/short_dataset/yaounde_covid_en.zip)
- Neighbourhood map: [cite_verte_health_areas.zip](https://github.com/kendavidn/uzh_webinar/raw/main/yaounde_covid/short_dataset/cite_verte_health_areas.zip)

Symptoms (`symp_*`) and contacts (`contact_*`) refer to the period since 1 March 2020.
